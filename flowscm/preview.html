PROJECT NOTE / HINT 1조

앱 제작 배경 · 사용 안내

업로드된 「SCM 수요계획 직무개선기획서 1조」 10쪽을 기반으로 구현했습니다.

설계 범위

1조 기획서의 핵심을 시연 가능한 운영 기능으로 변환

문제 정의분산된 판매·딜러 데이터, 반복 분석, 불필요한 승인 대기(2~5쪽). 실제 기업 내부 프로세스는 검증되지 않았습니다.
개선 전략ECRS의 통합(C), 순서 조정(R), 불필요 검토 제거(E), 예외 기준 간소화(S)를 적용했습니다(6쪽).
데이터 활용통합/시각화 → 통계 기반 예측 → 규칙 기반 처리. 실제 AI 모델 학습·ERP 연동은 하지 않았습니다(7쪽).
통제 기준판단 A는 데이터 품질, 판단 B는 예외 협의 필요성입니다. 허용 오차·CAPA·공급 위험은 실습용 사용자 설정값입니다.
실적 검증기획서의 리드타임 7→4일, 주 3→1회, 오차율 15→10%는 가정치입니다. 앱에서는 가짜 성과로 표시하지 않습니다(8~9쪽).

사용 순서

1 데이터 통합 탭에서 관측값을 추가하거나 CSV를 불러옵니다.
2 수요예측·판단에서 차량군, 차기 수주, 허용 오차 등을 설정합니다.
3 시뮬레이션 실행으로 자동 확정/검토 필요를 분기합니다.
4 예외·승인함에서 사유를 남기고 수동 승인하거나 보류합니다.
5 CSV 내보내기로 확정 수요계획을 다음 부서에 전달할 수 있습니다.

데이터 보존 · 보안

모든 데이터는 웹 브라우저의 로컬 저장소(localStorage)에만 저장됩니다. 서버, 계정, 외부 API, 클라우드 전송은 없습니다. 브라우저 저장 데이터를 지우거나 다른 기기에서 열면 기록은 공유되지 않습니다.

시뮬레이션의 한계 · 수요예측은 단순 가중평균 또는 선형 추세이며, 오차 비교는 예측량과 같은 계획월의 확정 수주량을 비교합니다. 확정 수주만으로 실제 미래 판매를 알 수 없으므로, 이 결과를 실적 예측 정확도의 증거로 해석해서는 안 됩니다.
